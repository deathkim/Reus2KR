Reus 2 한국어 플러그인 - CSV 수정에 강한 버전

지원 사항
* ko.csv에 있는 한국어 번역문을 수정하거나 줄을 추가해도 각 번역 레코드를 보존합니다.
* CRLF / LF / CR 줄바꿈을 읽을 때 LF로 통일합니다.
* 원래 게임에 존재하는 145개의 여러 줄 번역 키를 인식합니다.
* 6,533개 번역 항목을 사용한 줄바꿈 변환 및 대표 번역문 수정 시험을 통과했습니다.
* 기존 단어 단위 줄바꿈, 조사 처리, Unknown 번역, 이동 안내문 번역은 유지합니다.
* CSV를 읽는 과정에서 오류가 발생하면 플러그인 로그에 기록하고 기본 로더로 되돌립니다.

주의
* ko.csv는 일반적인 쉼표 CSV가 아니라 [원문 키] + GS(0x1D) + [번역문] 파일입니다.
* 키 또는 GS 문자(눈에 보이지 않는 구분자)를 수정/삭제하면 복원할 수 없습니다.
* 텍스트 편집기의 자동 줄바꿈이 아닌 실제 줄바꿈은 읽기 시 LF로 저장됩니다.
* 파일을 저장한 다음 게임을 재시작해야 수정 번역이 반영됩니다.
* Excel 등에서 저장해 GS 구분자를 없애면 동작하지 않습니다.

빌드 방법
1. dotnet SDK 설치
2. C:\My Games\Reus 2 Jurassic에 설치된 게임/BepInEx 참조 DLL 필요
3. PowerShell에서 build.ps1 실행
4. bin\Release\netstandard2.1\Reus2KR.dll을 기존 플러그인 DLL과 교체

개발 환경에 .NET SDK 및 Unity/BepInEx 참조 DLL이 없어 DLL은 여기서 컴파일하지 않았습니다.
